# TeacherTrack

## Teacher Performance & Development Tracking System

TeacherTrack is a simple web-based system designed to help schools manage and monitor teacher performance and professional development.

The system allows administrators to keep teacher information, attendance records, training records, student feedback, and lesson plans in one place.

---

## Features

- Teacher Profiles
- Add New Teachers
- Attendance & Punctuality Tracking
- Training & Certification Records
- Student Feedback
- Lesson Plan Management
- Performance Analytics
- Admin Dashboard
- Login System
- Logout System
- Automatic Teacher Dropdowns
- Local Data Storage

---

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

---

## How to Use

1. Open the TeacherTrack website.
2. Login using:

   **Username:** `admin`

   **Password:** `1234`

3. Use the navigation menu to access the different sections.
4. Add or update teacher information.
5. Record attendance.
6. Add training and certification records.
7. Add student feedback.
8. Create lesson plans.
9. View analytics and the Admin Dashboard.
